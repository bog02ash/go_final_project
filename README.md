# Описание проекта 
Это веб-приложение аналог TODO-листа. Веб-приложение представляет собой планировщик задач. Пользователь может создавать, удалять, редактировать и отмечать задачи как выполненные. Так же веб-приложение осуществляет повторение задач с интервалом в дни и годы.
# Основной функционал
1. Создание, удаление, редактирование и отметка выполнения задач
2. Повторение задач с итервалами в дни и годы.
3. Хранение задач в базе данных SQLite
4. Поиск задач по словам и датам
5. Аутентификация пользователя через JWT-токен

# Выполение задания повышенной сложности 
1. Поддержка переменной окружения TODO_PORT 
2. Поддержка переменной окружения TODO_DBFILE
3. Поиск задач по слову или дате
4. Создание докер-образа

# Переменные окружения 
TODO_PORT - порт для запуска сервера 
TODO_DBFILE - путь к файлу базы данных 
TODO_PASSWORD - пароль для аутентификации

# Инструкция по запуску кода локально
1. Необходимо иметь на компьтере уже установленные Go 1.24 и выше, SQLite.
2. Клонировать репозиторий из GitHub
   В терминале необходимо выполнить команду 
   git clone git@github.com:bog02ash/go_final_project.git
3. Перейти в каталог 
   cd go_final_project
4. Инициализировать модуль
   go mod tidy
5. Запустите веб-приложение
   go run main.go
6. Открыть в браузере ссылку http://localhost:7540

# Инструкци по запуску тестов 
1. Запустить сервер:
    go run main.go
2. Для запуска всех тестов в терминале необходимо выполнить команду
   go test ./tests -v

# Для запуска тестов с аутентификацие
1. Запустите сервер:
    go run main.go
2. Откройте в браузере ссылку http://localhost:7540
3. Ввести пароль, который хранится в переменной окружения TODO_PASSWORD (хранится в файле .env)
4. После корректного ввода пароля вам выдадут токен, его необходимо вписать в переменную Token в tests/settings.go
5. Сохраните файл и выполните команду
   go test ./tests/... -v

# Сборка обараза
1. Необходимо запустить докер и в директории проекта выполнить команду
  docker build --tag my-app:v1 .
2. Что бы запустить контейнер необходимо выполнить команду
  docker run -e TODO_PASSWORD=12345 -p 7540:7540 my-app:v1
Мы передали пароль при запуке т.к не стоит хранить пароли в ENV прямо в Dockerfile
3. Откройте в браузере ссылку http://localhost:7540
